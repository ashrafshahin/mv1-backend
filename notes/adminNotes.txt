pending → rejected

1. totalVendors: { $sum: 1 }, 
akta akta kore vendor ja ase sob chole asbe ai command er modhome

2. approvedVendor: {$sum: { $cond: [{ $eq: ['$status', 'approved'] }, 1, 0] } },

1 = add 1 until search complete
0 = no more
$cond = condition
$eq = equal 


Learning Point
তুমি এখন Admin Action Pattern শিখছো।
Approve, Reject, Suspend, Reactivate — সব controller-এর structure প্রায় একই হবে:
1. Get ID
2. Find Vendor
3. Validate Role
4. Validate Current Status
5. Update Status
6. Save
7. Return Response
