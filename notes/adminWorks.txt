Multi-vendor eCommerce project-এ Admin related কাজ অনেক বড় হয়।
Admin Dashboard এর প্রধান Modules

1. Vendor Management

Admin Vendor approve/reject করবে।

Features:
Pending vendors list
Approve vendor
Reject vendor
Suspend vendor
Reactivate vendor
Vendor details view
Vendor documents (NID, Trade License)
Vendor Status Lifecycle
pending
   │
   ├── approve → active
   │
   └── reject → rejected

active
   │
   └── suspend → suspended

suspended
   │
   └── reactivate → active

Schema example:

status: {
    type: String,
    enum: ['pending', 'active', 'rejected', 'suspended'],
    default: 'pending'
}
